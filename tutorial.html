EMLETTER · APRENDE A CREAR

Guía para dar vida a tus palabras.

Desde la primera frase hasta el último detalle: aprende a escribir, personalizar y compartir una carta con EmLetter. También encontrarás una guía para conversar con otra persona.

✎  Comenzar a editar ↗ ☏  Abrir chat ↗

01 Primeros pasos

Abrir el editor

Entra en Comenzar a editar para abrir tu espacio de escritura. Verás una hoja donde redactar tu carta, una barra para dar formato al texto y los ajustes de diseño.

No necesitas crear una cuenta para escribir. Puedes probar distintos estilos antes de generar el enlace que compartirás.

Escribir y dar formato

Haz clic en la hoja y empieza a escribir. Selecciona una palabra, una frase o un bloque para cambiar su tipografía, tamaño, color, alineación o estilo. También puedes añadir títulos, listas, citas, enlaces y tablas desde la barra del editor.

ConsejoSi quieres resaltar una palabra sin modificar todo el párrafo, selecciónala antes de usar las herramientas de formato.

Usar EmLetter en móvil

En un teléfono, la interfaz se adapta a una experiencia similar a una aplicación. Usa los apartados inferiores para encontrar las opciones de edición, inserción y diseño sin ocupar toda la pantalla con herramientas.

02 Personalizar tu carta

Elegir una atmósfera

Las atmósferas son puntos de partida para tu diseño. Puedes escoger entre Tinta, Bruma y Ceniza, ajustar su apariencia o crear una atmósfera personalizada para reutilizarla más adelante.

Rueda cromática y HEX

Al pulsar un control de color se abre una rueda cromática: elige un tono arrastrando el selector y ajusta su luminosidad. También puedes escribir directamente un valor hexadecimal, como #472A59, para obtener un color exacto.

Imágenes, adornos y firma

La herramienta Imagen te permite insertar una imagen y ajustar su tamaño y colocación. En el panel de diseño puedes cambiar los ornamentos, el icono central, el icono final, las líneas decorativas y el estilo de la firma.

Texto y emoji libres

Con Texto libre y Emoji libre puedes añadir elementos independientes y situarlos dentro de la carta. El editor también permite activar la colocación libre en determinados elementos mediante doble clic.

Cuando termines de mover un elemento, fíjalo para continuar escribiendo normalmente. Comprueba el resultado con la vista previa.

03 Compartir y exportar

Vista previa

Pulsa Vista previa para revisar la composición de la carta como la verá su destinatario. Si quieres cambiar algo, regresa al editor y sigue ajustando los detalles.

Generar un enlace

Cuando estés conforme, selecciona Generar link y después Copiar. El enlace incluye el contenido y la configuración visual de la carta para que otra persona pueda abrirla.

ImportanteCompartir un enlace permite leer la carta a cualquiera que lo tenga. La compresión del contenido no equivale a cifrado.

Descargar como imagen

También puedes pulsar Descargar imagen para guardar una versión visual de la carta. Es una alternativa útil si prefieres enviar una imagen en lugar de un enlace.

04 Conversar en EmLetter

Conectar mediante ID

Abre el chat de EmLetter. Recibirás un ID de cinco cifras; compártelo con la persona con quien quieres conversar. Para iniciar una conversación, introduce su ID en el campo ID del par y pulsa Conectar.

Mensajes y archivos

Una vez conectados, podrás intercambiar mensajes y archivos. El chat muestra la hora, las confirmaciones de recepción y un indicador cuando la otra persona está escribiendo. Las imágenes, el audio y el video pueden mostrarse dentro de la conversación.

Desconectar

Al pulsar Desconectar, la conexión termina en ambos extremos y la interfaz vuelve al estado inicial. Si quieres conversar de nuevo, introduce el ID de la otra persona y establece una nueva conexión.

05 Consejos y privacidad

Antes de cerrar

Comprueba el resultado de tu carta antes de compartirla. Para evitar perder trabajo, conserva el enlace generado o la imagen descargada: el editor no debe considerarse un sistema de borradores permanentes.

Tus enlaces y datos

El contenido de una carta compartida puede recuperarse a partir de su enlace. En el chat, el ID de cinco cifras sirve para localizar a otra persona, pero no es una contraseña. Evita enviar información especialmente sensible por cualquiera de estas vías.

Puedes consultar más detalles en nuestra política de privacidad.
